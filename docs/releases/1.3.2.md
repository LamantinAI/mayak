# Mayak 1.3.2

Патч исправляет создание бэкенда из шаблона и обнаружение тестов в готовом продукте.

- **База данных.** При `make bootstrap … DB=postgres` миграция и HTTP-проверка используют локальный порт PostgreSQL, выделенный текущему рабочему дереву. Если команда запуска базы не подтвердила порт, bootstrap останавливается до миграции. Адрес пользовательской БД в `.env` сохраняется для обычного запуска.
- **Файлы проекта.** Перед извлечением примера bootstrap проверяет назначения и содержимое удаляемых файлов. При конфликте с черновиком или закоммиченной правкой он указывает путь. Проверка распространяется и на сам скрипт извлечения. Существующие идентичные копии примера и миграции допускаются.
- **Тесты.** `make test`, `make gate-tests` и `make verify` используют обнаружение pytest от корня `tests/`. Падающий тест в новом каталоге продукта теперь останавливает сдачу. Функциональные тесты по-прежнему запускаются в Docker.

В существующем продукте в первую очередь обновите `scripts/run_all_tests.py`. Правки bootstrap и извлечения нужны там, где эти операции ещё выполняются. Для перехода с 1.3.1 миграция схемы приложения не требуется. [Руководство по обновлению](../upgrades.md)
