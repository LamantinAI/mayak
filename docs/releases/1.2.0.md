# Mayak 1.2.0

Маяк упрощает запуск нового API и даёт проверяемый путь от первой вертикали до изменения и
снятия действующего контракта. В релиз входят общая проверка обработчиков, единый выбор
PostgreSQL для worktree и удобное чтение трассы по короткому идентификатору.

## Что изменилось

- `make bootstrap` настраивает профиль PostgreSQL или stateless, выносит эталонную вертикаль
  в scaffold и проверяет HTTP readiness.
- `make gate-fast` проверяет размер модулей сразу при редактировании. Порог размера сохранён.
- `make verify` отделяет проверку всех HTTP-обработчиков от покрытия Git-диффа. В выводе видны
  база, HEAD, количество незакоммиченных путей и результат Docker E2E. Чистая копия без базы
  сравнения может подтвердить здоровье сервиса и явно сообщает, что дифф не измерялся.
- Make, прямой запуск и Alembic читают назначенный порт PostgreSQL из текущего worktree. Явные
  настройки подключения сохраняют приоритет. Пользовательский `.env` остаётся источником
  конфигурации и не переписывается при выборе порта.
- SQL-пример использует цельные параметризованные запросы. У новых внешних ключей есть
  стабильные имена для генерации обратимых миграций.
- `format-trace` принимает уникальный префикс идентификатора. Просмотрщик показывает число
  отфильтрованных span. Stateless-рецепт содержит пример безопасной записи исхода.
- Mock-режим запускается без импорта SDK провайдера. Live-режим по-прежнему инициализирует
  клиент при старте. Для тестов доступны сценарии пакетных вызовов инструментов.

## Проверено

Извлечённый stateless-проект содержит 21 919 непустых строк Python при лимите 22 000.

На предрелизном снимке восемь независимых сессий Grok 4.7 XHi собрали сервисы во всех четырёх
сочетаниях PostgreSQL и LLM. Каждый прогон включал создание, сопровождение, снятие работающей
функции и расследование инцидента. Во всех восьми прошли финальный `verify` и предметный Docker
E2E. Четыре PostgreSQL-сервиса проверили миграции уже заполненных баз. Эти результаты относятся
к синтетическим проектам и продолжению работы в своей сессии.
