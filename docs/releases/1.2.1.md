# Mayak 1.2.1

Патч-релиз о честной сдаче работы агентом: шаблон перестаёт советовать неработающую команду,
`make verify` называет, что именно он измерил, а правила говорят, чем подтверждать сдачу.
Под `project/` и `alembic/` изменений нет.

## Что изменилось

- **Строгая проверка миграций без базы.** Отказ `migrations.database_required` больше не
  советует `MIGRATIONS_ALLOW_SKIP=1`: под `make verify` и `--require-database` этот переключатель
  не действует. Вывод называет правило, одно действие по месту запуска (явно заданная цель или
  CI; нет настроек подключения — сначала `make init-project`; иначе `make db-up-worktree` для
  этой копии), строгую команду повтора и playbook. Playbook согласован с выводом и не предлагает
  общую базу Compose.
- **Область `make verify`.** После строки `verify: change:` печатается строка `verify: scope:`:
  - `change since <ref> (explicit base)` — база передана через `DIFF_COMPARE_BRANCH`;
  - `change since <ref> (auto base)` — найдена `origin/HEAD`, `origin/main` или `origin/master`;
  - `project only (clean tree, no base)` — чистое дерево без базы;
  - `uncommitted paths only (no base); commits are not measured` — базы нет, измерены только
    незакоммиченные пути. В этом режиме строка Docker E2E N/A говорит, что коммиты не
    просматривались, печатается команда полной сдачи
    `make verify DIFF_COMPARE_BRANCH=<starting commit>`, а итог —
    `verify: PASS — project and uncommitted paths only; commits were not measured`.
- **Правила сдачи.** `AGENTS.md` просит цитировать строку области вместе с итоговой и описывать
  изменённое поведение: действие пользователя, ожидание, наблюдение и команду или тест.
- **Где описан продукт.** `PROJECT.md` — актуальное описание продукта; `README.md` — запуск
  и проверка; `docs/project_context.json` — обязательные метаданные и происхождение из шаблона,
  а не вторая копия описания.
- **Перенос по диффу деревьев.** В [руководстве по обновлению](../upgrades.md#port-by-tree-diff)
  появился раздел «Port by tree diff»: список путей по `template.source_tree`, файлы, которые
  сервис не менял, берутся из целевой версии целиком, изменённые переносятся руками; есть
  запасной путь. `make upgrade-check` больше не называет фиксированную версию.

## Что не изменилось

- Коды возврата `make verify` и `scripts/validate_migrations.py`, набор запускаемых проверок,
  выбор Docker E2E и строка `verify: change:`.
- Строгий режим миграций: `make verify` и `--require-database` по-прежнему не допускают пропуск,
  `MIGRATIONS_ALLOW_SKIP=1` по-прежнему снимает только строгость от `CI`, нестрогий пропуск
  печатает прежнее `MIGRATIONS NOT VERIFIED`.
- Итоговые строки режимов с явной базой, найденной базой и чистого дерева без базы.
- Схема `docs/project_context.json`, bootstrap и проверка метаданных.

## Обновление существующего сервиса

Сервис на 1.2.0 переносит релиз разделом
[«Port by tree diff»](../upgrades.md#port-by-tree-diff): изменения касаются
`scripts/validate_migrations.py`, `scripts/verify_change.py`, `scripts/check_template_updates.py`
и текстов. Скрипты, которые сервис не менял, заменяются целиком; `docs/agent_rules.md` сливается
с собственными строками сервиса, затем `make refresh-agent-docs`.
